# The Aiman's School Umerkot - School & College Portal 🏫✨

Welcome to the local repository of **The Aiman's School Umerkot** website! This is a state-of-the-art, fully responsive, and highly interactive school portal built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**. It features a premium, luxury design tailored with a sophisticated Navy Blue (`#0B1F3A`) and Gold (`#D4AF37`) color palette.

## 🇵🇰 اردو / Roman Urdu Guide (جلدی شروع کرنے کا طریقہ)

یہ ویب سائٹ ایک جدید **React + Vite** ایپلیکیشن ہے۔ اسے اپنے کمپیوٹر پر لوکلی چلانے کے لیے مندرجہ ذیل آسان طریقے اپنائیں:

### طریقہ 1: ڈبل کلک رنر (سب سے آسان طریقہ)
میں نے آپ کے لیے فولڈر میں ایک فائل بنائی ہے جس کا نام `run-local.bat` ہے۔
1. اپنے پروجیکٹ کے فولڈر میں جائیں۔
2. فائل **`run-local.bat`** پر ڈبل کلک کریں۔
3. یہ فائل خودکار طور پر چیک کرے گی کہ آیا آپ کے پاس Node.js انسٹال ہے، ضروری پیکجز انسٹال کرے گی، اور سرور کو چالو کر دے گی!
4. سرور چلنے کے بعد، براؤزر میں دی گئی لوکل لنک (جیسے `http://localhost:3000`) پر کلک کر کے اپنی خوبصورت ویب سائٹ لوکلی دیکھیں۔

### طریقہ 2: کمانڈ لائن (Command Prompt) سے چلانا
اگر آپ خود چلانا چاہتے ہیں:
1. اپنے کمپیوٹر میں **Command Prompt** (کمانڈ پرامپٹ) کھولیں اور اس پروجیکٹ کے فولڈر میں جائیں۔
2. تمام ضروری فائلز انسٹال کرنے کے لیے یہ کمانڈ چلائیں:
   ```bash
   npm install
   ```
3. پیکجز انسٹال ہونے کے بعد، ویب سائٹ کو شروع کرنے کے لیے یہ کمانڈ چلائیں:
   ```bash
   npm run dev
   ```
4. اب اپنے براؤزر میں **`http://localhost:3000`** کھولیں۔

> **نوٹ:** اگر آپ کے پاس **Node.js** انسٹال نہیں ہے، تو پہلے [Node.js کی آفیشل ویب سائٹ](https://nodejs.org/) سے **LTS ورژن** ڈاؤن لوڈ اور انسٹال کریں۔

## 🇬🇧 English Guide (Quick Start Guide)

This application is built using modern front-end technologies. To run it locally on your Windows machine, you have two options:

### Method 1: The Quick Double-Click (Recommended)
I have created a special Windows automation script named `run-local.bat` in the root of your project directory:
1. Navigate to your project folder.
2. Double-click the file **`run-local.bat`**.
3. It will automatically detect **Node.js**, install any missing dependencies, bypass PowerShell execution policies, and fire up your local development server.
4. Once it is running, it will display the local link (e.g., `http://localhost:3000`). Simply open that in your web browser!

### Method 2: Manual Terminal Execution
If you prefer running commands manually:
1. Open your terminal/command prompt and navigate to the project directory:
2. Install the node packages:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
4. Open the development link: **`http://localhost:3000`** in your browser.

## 🎨 Design & Aesthetics
This website boasts a custom luxury layout, perfect for a premier educational institute:
- **Primary Color Scheme**: Harmonious Royal Navy (`oklch(0.22 0.06 258)`) and Sleek Dark Modes.
- **Accents**: Luxury Rich Gold (`oklch(0.78 0.13 87)`) elements and smooth hover micro-animations.
- **Typography**: Custom loading of **Inter** (for standard readability) and **Playfair Display** (for elegant headings) fonts.
- **Visuals**: Glassmorphism (`backdrop-filter`) layout cards, animated entrance effects (`tw-animate-css`), and custom visual layouts.

## 🛠️ Key Portals & Pages Included
1. **Home Page**: Complete with statistics, Principal's message, testimonials, announcements, and school highlights.
2. **Academic Portals**: Details of curriculum from Montessori to Higher Secondary/College levels.
3. **Admissions Center**: Integrated application form for new students.
4. **Campus Gallery**: Filterable, beautiful high-resolution image showcase.
5. **Notice Board**: High-priority real-time school notices and circulars.
6. **Results Portal**: Search engine to fetch student academic results.
7. **Contact Center**: Interactive maps, contact details, and an inquiry form.
8. **Admin Panel**: Secure dashboard to manage notices, results, blogs, teacher details, and parent inquiries.
